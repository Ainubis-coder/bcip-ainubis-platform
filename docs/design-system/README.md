# BCIP Enterprise Design System & Design Tokens Documentation

The **BCIP Enterprise Design System** (`@bcip/ui`) provides the centralized design tokens, foundational primitives, accessible components, and composite data patterns for the Body Corporate Intelligence Platform.

## Core Philosophy

- **Restrained Enterprise Aesthetic**: Built for managing agents, trustees, auditors, and property directors. Avoids frivolous AI glows, candy-pill tags, and ungrounded scoreboard metrics.
- **60-30-10 Color Discipline**: 60% neutral canvas (`#020617`), 30% structural surfaces (`#0F172A`, `#1E293B`), 10% purposeful accent budget.
- **Zero-Pill Discipline**: Non-interactive metadata is separated cleanly with typographic characters (`·`, `/`) instead of boxed badges.
- **Strict Tabular Numerals**: Enforces monospace tabular figures (`font-mono tabular-nums`) on all monetary values, percentages, and metrics.
- **Ainubis Intelligence Separation**: Clean demarcation between passive observation, inferred insight, strategic recommendation, urgent alert, and human-in-the-loop approval gates.
